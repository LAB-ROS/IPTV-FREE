IPTV Player para Smart TV

Este player ja carrega automaticamente uma lista publica de canais (iptv-org) ao abrir. Se preferir, cole abaixo o endereco (URL) da sua propria playlist M3U/M3U8, ou cole o conteudo M3U diretamente. Use as setas do controle remoto para navegar e OK/Enter para selecionar.

Use "Carregar por URL" quando o link aponta para um arquivo de lista com varios canais. Use "Adicionar como canal único" quando o link e o proprio stream de video (ex.: encurtadores como jmp2.uk, ou uma URL .m3u8/.mp4 de um unico canal) — nesse caso o navegador nao precisa ler o conteudo, so reproduzir. Obs.: cada servidor decide se libera ou nao a leitura via navegador (CORS); por isso alguns links funcionam direto com "Carregar por URL" e outros so funcionam como "canal único" (o player ja tenta isso automaticamente quando detecta o bloqueio).
